# Потенциальные функции

Этот список содержит идеи, которые не входят в ветку
`feature/reliability-settings-self-check`. Поддержка нескольких и свёрнутых окон
намеренно не включена в этот список.

## 1. Визуальная диагностика распознавания

Показывать последний захваченный кадр с рамками найденного диалога, кнопок,
области OCR и панели персонажа.

## 2. Тестовый режим без кликов

Выполнять полный анализ и показывать предполагаемое действие без управления
мышью.

## 3. Адаптивная частота проверки

Использовать редкие проверки в обычном состоянии и временно повышать частоту
после появления признаков диалога.

## 4. Управление состоянием из трея

Добавить «Пауза», «Продолжить», «Проверить сейчас» и краткое отображение текущего
состояния.

## 5. Настраиваемые правила решений

Поддержать порог процента, дополнительные шаблоны суффикса и явные приоритеты
правил.

## 6. История действий и уведомления

Хранить ограниченную историю решений и по выбору показывать Windows-уведомления
о клике, пропуске или ошибке. Экспорт истории должен оставаться явным действием
пользователя.
