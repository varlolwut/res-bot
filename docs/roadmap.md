# Потенциальное развитие

В этом списке остаются функции, которые не входят в текущий релиз:

1. Режим обучения на пользовательских скриншотах с предварительным просмотром
   найденных областей OCR и панели персонажа.
2. Профили конфигурации для разных серверов и вариантов интерфейса.
3. Уведомление в трее о последнем действии и причине принятого решения.
4. Экспорт диагностики вручную выбранным файлом для передачи разработчику.
5. Режим только уведомления: обнаружить запрос, но не перемещать курсор и не
   нажимать кнопку.
6. Настраиваемые правила для процентов, отличных от `0%` и `100%`, если такие
   варианты появятся на сервере.

Поддержка нескольких окон и работа со свёрнутым окном намеренно вынесены за
пределы этого списка и текущего MVP.
